# PRO1
Workspace for PRO1 subject of UAP Upper Austria

# Prerequisites
FreePascal Compiler [FCP](https://www.freepascal.org/download.html)

To enable the correct snippets in VS Code, the following file must be replaced by the file pascal.json be replaced from the e-learning course:

• Windows: 
%USERPROFILE%\.vscode\extensions\alefragnani.pascal
10.0.0\snippets\pascal.json 

• Linux / macOS: 
$HOME/.vscode/extensions/alefragnani.pascal
10.0.0/snippets/pascal.json
